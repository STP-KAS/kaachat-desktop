# Disclaimer

**Experimental only. Not a product.**

This repository is independent desk work. It is not Kaspa core.

There is no spendable native L1 stable on Kaspa, and no credible alternative on the horizon. Sequencing commitments on L1 are a consensus primitive; a settled sequencing product for applications is not in place. Until both the unit of account and the sequencing path are settled, building production dapps on Kaspa is not a useful allocation of time or capital.

Filter every GitHub claim that says it “shipped”:
https://x.com/kaspaglobal/status/2100536064683176270

A proposal is not a release. A development branch is not a product. A node release is not wallet support.
